# 🌿 Eunice Portfolio

A modern, minimal **dark-green × black** themed personal portfolio built using **React.js**.

## 🚀 Features

* Typing intro + clean hero section
* About Me with profile picture
* Skills with icons (HTML, CSS, JS, React, Figma, Python)
* Projects section (3 featured projects)
* Fun facts section
* Contact section
* Fully responsive design

## 📁 Folder Structure

```
src/
  components/
  pages/
  data/
  assets/
  App.js
  index.js
styles.css
```

## 🛠 Tech Stack

* React.js
* JavaScript
* Custom CSS

## ⚙️ Run Locally

```bash
npm install
npm start
```
